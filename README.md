# Job Tracker API

A Spring Boot REST API for tracking job applications.

## Tech Stack

* Java 21
* Spring Boot 3
* Spring Data JPA
* MySQL
* Maven
* Swagger/OpenAPI

## Features

* User Management
* Job Application Management
* Dashboard Statistics
* CRUD Operations
* REST APIs

## Endpoints

### Users

* POST /api/users
* GET /api/users

### Jobs

* POST /api/jobs
* GET /api/jobs
* DELETE /api/jobs/{id}
* GET /api/jobs/dashboard

## Database

* MySQL
* users table
* job_applications table
